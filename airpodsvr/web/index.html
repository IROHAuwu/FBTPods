    貼合重置怎麼貼

    躺著、盤腿時也準。手把有搖桿和按鍵的那一面朝外、扳機那一側貼著脛骨、前端朝腳掌，和校正精靈登記時相同。手把短震一下是成功，震兩下是沒貼平。

    改按鍵：SteamVR 設定 → 控制器 → 顯示綁定介面 → FBT Pods。Index 手把用 B／A，Vive 手把用選單鍵。

    身體由 SlimeVR Server 計算。身體比例與配戴校正請在 SlimeVR 裡做，這一頁不適用。

    校正精靈

    約 1 分鐘，戴著頭顯
    1. 站直雙腳平行、看正前方
    2. 滑雪姿勢膝蓋往前彎、腳掌貼地，量測綁帶角度
    3. 再站直完整重置，同時量身高
    4. 左右腳各伸直往前校正腳的朝向，可略過
    5. 手把貼腿每個腿部感測器登記一次貼合重置
    6. 平常的站姿與坐姿自動對齊的目標，坐姿可略過

    每一步都有姿勢圖。按「下一步」或長按左手 Y／B，嗶聲結束前保持不動。要先開始追蹤。

    腳的朝向校正

    腳伸直往前，畫面上卻偏向一邊時

    面向正前方，把一隻腳伸直往正前方伸出去，膝蓋打直，按下後保持到嗶聲結束。左右腳各做一次。

    結果會記住，完整重置不會蓋掉它。
